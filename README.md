# AI Telegram Bot: Психологическая поддержка и Генерация контента

Телеграм-бот с элементами искусственного интеллекта, разработанный в рамках курсовой работы. Бот использует нейросеть **GigaChat (Sber)** для общения с пользователями и предоставления инструментов копирайтинга.

## 🚀 Основные функции

*   **🧠 Режим Психолога**: Эмпатичное общение, поддержка в трудных ситуациях, активное слушание.
*   **✍️ Режим Копирайтера**: Генерация постов, статей и идей для социальных сетей.
*   **🧘 Дыхательная гимнастика**: Интерактивное упражнение (техника 4-7-8) на основе асинхронных алгоритмов.
*   **🆘 Экстренная помощь**: Быстрый доступ к верифицированным телефонам доверия и психологическим службам.

## 🛠 Технологический стек

*   **Язык**: Python 3.10+
*   **Библиотека бота**: Aiogram 3.x (Asynchronous)
*   **ИИ Модель**: GigaChat API (Sber)
*   **Управление состоянием**: FSM (Finite State Machine)
*   **Конфигурация**: Python-dotenv

## 📥 Инструкция по установке и запуску

### 1. Требования
Убедитесь, что у вас установлен Python версии 3.10 или выше.

### 2. Подготовка файлов
Склонируйте репозиторий или скачайте архив с кодом:
```bash
git clone https://github.com/ВАШ_ЛОГИН/ai-psy-bot.git
cd ai-psy-bot
```

### 3. Создание виртуального окружения
В корневой папке проекта выполните команды:

**Для Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**Для macOS/Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 4. Установка зависимостей
Установите необходимые библиотеки одной командой:
```bash
pip install -r requirements.txt
```

### 5. Настройка ключей доступа (.env)
Создайте в корневой папке файл с названием `.env` и вставьте в него ваши токены:
```env
BOT_TOKEN="ВАШ_ТОКЕН_ОТ_BOTFATHER"
GIGACHAT_TOKEN="ВАШИ_АВТОРИЗАЦИОННЫЕ_ДАННЫЕ_ОТ_СБЕРА"
```

### 6. Запуск
```bash
python main.py
```

## ⚠️ Важные примечания (Troubleshooting)

1.  **VPN**: В связи с сетевыми ограничениями, для корректной работы и связи с Telegram Bot API, серверная часть бота (ваш компьютер) должна работать с **включенным VPN**. При этом запросы к GigaChat проходят через стандартные российские шлюзы.
2.  **GigaChat Scope**: В проекте используется область доступа для физических лиц (`GIGACHAT_API_PERS`). Убедитесь, что при получении токена в Сбер Studio вы выбрали именно этот тип доступа.
3.  **Безопасность**: Файл `.env` добавлен в `.gitignore` и не должен передаваться в публичный доступ.

## 📂 Структура проекта

*   `main.py` — Точка входа, запуск бота.
*   `handlers.py` — Логика обработки сообщений и команд.
*   `services.py` — Взаимодействие с API GigaChat и управление памятью.
*   `keyboards.py` — Описание интерфейса и кнопок.
*   `states.py` — Классы состояний (FSM).
*   `config.py` — Загрузка настроек из окружения.
